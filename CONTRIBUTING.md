# Contributing

This repo is the curated, accepted destination for One Horizon skills — not
the intake form. If you have a skill idea and haven't already gone through
the submission process for the parent initiative, start there first.

**How to add or update a skill** (validation rules, OpenAI metadata, index
regeneration, terminology, website `index.json` contract) lives in
[AGENTS.md](AGENTS.md).

Install instructions for end users stay in [README.md](README.md).
